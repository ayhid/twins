## Phase Goal

ROADMAP goal (verbatim): The scan pipeline runs inside `twins-core`, and any caller (CLI now, app and agent later) can follow its progress by stage and cancel it, on the Rust 1.90 toolchain Tauri needs.

The ROADMAP marks this phase `**Mode:** mvp`, but its goal line is not in user-story form. The planner did not invent a story; run `/gsd-mvp-phase 1` if you want the As a / I want to / so that framing added.

<objective>
Tracer slice of the whole phase: `twins scan` and `twins report` get their report from a new `twins_core::pipeline::scan(spec, &observer, &cancel)`, with output locked byte-for-byte by characterization tests written and committed first. `report::Meta` (including its dry-run flag, derived from a new `RunMode`) is built only in core.

Purpose: proves the D-01 architecture end to end (core orchestrates, the CLI only renders) on one real path before any expansion. Delivers CORE-03 completely and the core half of CORE-01/CORE-02 (observer contract, one CancelToken driving walk and hashing, cancellation between stages).
Output: `observe.rs`, `pipeline.rs`, a hollowed-out `run.rs`, CLI characterization tests, `pipeline_test.rs`.
</objective>
