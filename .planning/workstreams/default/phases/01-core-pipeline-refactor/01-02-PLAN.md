## Phase Goal

ROADMAP goal (verbatim): The scan pipeline runs inside `twins-core`, and any caller (CLI now, app and agent later) can follow its progress by stage and cancel it, on the Rust 1.90 toolchain Tauri needs. (Not in user-story form. The planner did not invent one; see plan 01-01.)

<objective>
Make every hashing stage observable: `group::find` announces the start of partial hash, full hash and verify with a `done == 0` marker, and `pipeline::scan` turns it into `Event::StageStarted { stage, step, steps }`. Any observer (the CLI now, the app later) then sees walk → size grouping → partial hash → full hash (→ verify) in order, can show `[3/4] partial hash`, and can cancel at any stage boundary.

Purpose: D-07, D-08 and D-10 (ordered, observable stages with an honest step counter), plus cancel-at-stage proof for D-05.
Output: marker in `find.rs`, mapping in `pipeline.rs`, new tests in `group_test.rs` and `pipeline_test.rs`.
</objective>
