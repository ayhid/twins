## Phase Goal

ROADMAP goal (verbatim): The scan pipeline runs inside `twins-core`, and any caller (CLI now, app and agent later) can follow its progress by stage and cancel it, on the Rust 1.90 toolchain Tauri needs. (Not in user-story form. The planner did not invent one; see plan 01-01.)

<objective>
Make the walk observable and promptly cancellable. While directories are listed (the slow part, where users waited with no feedback), the pipeline reports how many files it has seen, which the terminal shows as `[1/4] walk  48 210 files`. A cancel raised during the parallel stat phase now stops it instead of being ignored until every file has been statted.

Purpose: D-05 (stop the walk promptly) and D-06 (walk file count), research Patterns 3 and 5.1.
Output: `walk_observed` in `walk.rs`, its crate-level re-export, cancel polls, tests in `scan_test.rs` and `pipeline_test.rs`.
</objective>
