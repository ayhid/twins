## Phase Goal

ROADMAP goal (verbatim): The scan pipeline runs inside `twins-core`, and any caller (CLI now, app and agent later) can follow its progress by stage and cancel it, on the Rust 1.90 toolchain Tauri needs. (Not in user-story form. The planner did not invent one; see plan 01-01.)

<objective>
Make hashing stop within one 256 KiB chunk of a cancel, even inside a multi-gigabyte file or on a slow external disk, without ever producing a digest of a partial file and without misreporting the interrupted file as unreadable.

Purpose: D-05 ("stop every hashing stage promptly, within about a second on a large tree"), research Pattern 5 (items 2 to 5) and Pitfalls 1 and 2. This keeps Phase 4's cache (CACHE-03) safe: a cancelled read is an error, never a cacheable digest.
Output: `full_cancellable` / `equal_cancellable` in `hash.rs`, a defaulted trait method in `hasher.rs`, cancel-aware `find.rs`, tests.
</objective>
