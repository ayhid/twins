## Phase Goal

ROADMAP goal (verbatim): The scan pipeline runs inside `twins-core`, and any caller (CLI now, app and agent later) can follow its progress by stage and cancel it, on the Rust 1.90 toolchain Tauri needs. (Not in user-story form. The planner did not invent one; see plan 01-01.)

<objective>
Wire Ctrl+C in the CLI to the core `CancelToken`. The first SIGINT raises the token, so the pipeline stops promptly (thanks to plans 01-05 and 01-06), the terminal observer clears the line, `scan cancelled` is printed on stderr, and the process exits 130 with nothing on stdout. A second SIGINT exits 130 at once, as the escape hatch for a read blocked on a stuck volume.

Purpose: success criterion 3 and CORE-02's user-facing half (D-02, D-03, D-04). Closes the phase with the full suite, the real-signal tests and a 1.90 run.
Output: signal-hook dependency (CLI only), SIGINT registration in run.rs, a cancelled arm in main.rs, ignored SIGINT tests.
</objective>
